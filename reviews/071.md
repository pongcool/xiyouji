## การตัดสินระหว่างแปล
- ย14 外公 → “ตา” ตามคำเรียกเดิม แต่เมื่อปีศาจถือเป็นแซ่ใช้ “ไว่/ไว่กง” พร้อมเชิงอรรถ 071-1; 外受傅訓 → “ภายนอกรับคำสอนจากครู” ให้คำว่าภายนอกอยู่ต้นวรรคตามมุก

- ย16 「無一個『老』字，不敢稱呼」 → “ไม่มีคำว่า ‘ท่านผู้เฒ่า’ ก็ไม่กล้าเรียก” คำยกย่องนำหน้า ไม่ใช่ความชรา ขอผู้ตรวจดู
- ย24 佛母懺悔以後 → “พระพุทธมารดาขมากรรมแล้ว” ประธานของ 懺悔 อาจเป็นพระพุทธมารดา (ทำพิธีขมาให้ลูกนก) หรือคนยิงที่ยอมรับผิด ไวยากรณ์ชี้พระพุทธมารดา จึงไม่เติมว่าใครสำนึกผิด ขอผู้ตรวจดู; 身耽啾疾 → “กายต้องทนโรคเจ็บ” 啾 สแกนตรงไฟล์ (หน้า PDF 928) อ่านเป็นโรคตามบริบท
- ย24 孔雀大明王菩薩 → “พระโพธิสัตว์นกยูงมหาวิทยาราชา” 明王 = vidyārāja
- ย27 蜇陽之毒 → “พิษต่อยฝ่ายชาย” อ่าน 陽 เป็นฝ่ายชาย สอดกับที่พระราชาและปีศาจแตะไม่ได้ ขอผู้ตรวจดู
