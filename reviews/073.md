## การตัดสินระหว่างแปล
- ชื่อบท 心主 → “เจ้าแห่งใจ” ตามชื่อบท 069; 破光 → “ทำลายแสง”
- ย1 劉阮天台洞 → “ถ้ำเขาเทียนไถของหลิวกับร่วน” พร้อมเชิงอรรถ 073-1
- ย3 面如瓜鐵 → “หน้าดั่งเหล็กสีแตง” ความไม่ชัด แปลตามตัวอักษร; 達達 → “ชาวตาตาร์”
- ย6 唾著臉 → “ถ่มน้ำลายทำหน้าบึ้ง” 唾 = ถ่ม แต่สำนวนอาจหมายถึงทำหน้าไม่พอใจ จึงรวมสองความ ขอผู้ตรวจดู; 陰人 → “คนฝ่ายหยิน” (หมายถึงผู้หญิง) คงคำตามต้นฉบับ; 裝幌子 → “ทำให้ข้าขายหน้า”
- ย9 หน่วย 分/釐 ถอดเสียง “เฟิน/หลี” ตามแบบหน่วยดั้งเดิม
- ย15 「唵」字真言 → มนตร์สัจจะอักษร “โอม”
- ย17 逞金吾 → “อวดศักดาดั่งทหารรักษาพระองค์” 金吾 ตำแหน่งทหารรักษาวัง ขอผู้ตรวจดู
- ย21 穿山甲 → “ตัวลิ่น”; 鯪鯉鱗 ชื่อเรียกที่สองถอดเสียง “หลิงหลี่หลิน” เพราะต้นฉบับยกเป็นชื่ออีกชื่อ และ ย24 ใช้ชื่อนี้
- ย22 陽溝 → “รางน้ำข้างทาง” คู่กับทะเลใหญ่ในวรรคก่อน
- ย25 那聖賢有些多怪人 → “ค่อนข้างชอบตำหนิคน” (怪 = ตำหนิ)
- ย25–ย33 毘藍婆 → “ผีหลานผอ” ถอดเสียงตาม X002 และตารางถอดเสียง (pí → ผี) แม้ “ผี” ในไทยแปลว่าผี; ทางเลือกอื่นคือรูปสันสกฤต “วิลัมพา” ตามชื่อรากษสีในสัทธรรมปุณฑรีกสูตร แต่ยังไม่มีหลักฐานว่าตัวละครนี้คือองค์เดียวกัน ส่งผู้ใช้พิจารณา
