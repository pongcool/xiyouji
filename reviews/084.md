## การตัดสินระหว่างแปล
- ชื่อบท 難滅伽持圓大覺 → “พรคุ้มครองยากจะทำลาย การตรัสรู้ใหญ่บริบูรณ์” อ่าน 伽持 = 加持; 法王成正體天然 → “ธรรมราชาสำเร็จกายแท้ตามธรรมชาติ” 法王 ในชื่อบทและกวี ย24 (法王滅法法無窮 / 管取法王成正果) ใช้ “ธรรมราชา” ให้เล่นคำกับ 滅法 ได้ ไม่ระบุว่าหมายถึงใครนอกจากที่ข้อความบอก
- ย2 滅法國 ถอดเสียง “แคว้นเมี่ยฝ่า” พร้อมเชิงอรรถ 084-1 ความหมาย “ทำลายธรรม” ตามแบบ 比丘國 (078-1); 送命王菩薩 แปลตามตัวในเครื่องหมายคำพูดเป็นชื่อล้อ; 黑話 → “พูดจาข่มขวัญ” ตามบริบทที่หญิงชราขู่ว่าไม่มีทาง
- ย7 คำพรรณนาผีเสื้อกลางคืน 形細翼磽 → “ร่างเล็ก ปีกเชิด” อ่าน 磽 ตามภาพปีกแข็งชัน ความของ 磽 ไม่ชัด ขอผู้ตรวจดู; 腐草中間靈應 → “อยู่กลางหญ้าเน่าก็มีฤทธิ์” ตามคติแมลงเกิดจากหญ้าเน่า
- ย14 販馬的客人尚還小 → “พ่อค้าม้ายังหนุ่มกันอยู่เลย” อ่าน 小 = อายุน้อย สแกนตรงไฟล์ (S119(4)) ขอผู้ตรวจดู; 相應 → “ถูกดี” อ่านเป็นภาษาพูดว่าราคาถูก (ราคาห้าเฉียน “ยังไม่พอเชิญสาว ๆ”); 客綱客紀 → “หัวหน้ากองพ่อค้าตัวจริง”
- ย15 庚申齋 → “เจเกิงเซิน” ถอดเสียงก้านฟ้ากิ่งดินตามแบบ 辛酉日 ไม่เติมเชิงอรรถเรื่องคติเฝ้าคืนเกิงเซิน
- ย20 一本一利 → “ได้กำไรเท่าทุน”
- ย21 巡城總兵 → “แม่ทัพตรวจเมือง”, 東城兵馬司 → “กรมทหารรักษาเมืองฝั่งตะวันออก”, 兵馬 → “เจ้ากรมทหาร”; คำพรรณนาม้า 款段 → “ม้าเดินเอื่อย”, 千金市骨 แปลตามตัวไม่ใส่เชิงอรรถ
- ย26 梓童 (พระราชาเรียกมเหสี) → “มเหสี”; 三屍呻咋 → “เทพสามศพครางลั่น” ตามแบบ 015/078
