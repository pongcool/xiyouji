## การตัดสินระหว่างแปล
- ชื่อบท 高老莊 → “หมู่บ้านเกาเหล่า” ถอดเสียง 高老 แปล 莊; ย5 ผู้พูดอธิบายว่าคนส่วนใหญ่แซ่เกา จึงไม่แปล 老 เป็นความชรา
- ย1 紅風洞 → “ถ้ำหงเฟิง” พร้อมเชิงอรรถ 018-1 (ล้อ 黑風 ที่ถอดเสียงตามเชิงอรรถ 016-5)
- ย5 「受他的清氣」 คู่กับ 「家長的屈氣受不了」 → “ต้องมารับโมโหเปล่า ๆ จากมันอีก” อ่าน 清氣 เป็นความรำคาญที่ไม่ควรได้รับ ไม่พบนิยามเฉพาะ ขอผู้ตรวจดู
- ย5 斂褌劄褲 → “รวบชายกางเกงผูกขากางเกงไว้กระชับ” (แต่งกายเดินทาง); 「才有買賣」 → “ถึงจะมีงานให้ทำ” (สิงเจ่อพูดถึงงานปราบปีศาจ)
- ย6, ย9, ย17 法師 → “อาจารย์ผู้มีวิชา” ไม่ใช้ “ธรรมาจารย์” ของแถวตำแหน่งสงฆ์ เพราะเกาไฉนับทั้ง 和尚 และ 道士 เป็น 法師 ที่เชิญมาแล้ว (แถว GLOSSARY ใช้คีย์วลี 尋訪法師/好法師/請個法師/請法師 เพื่อไม่ทับแถว 法師 เดิมในเครื่องตรวจ ซึ่งยังชี้ 法師 ห้าครั้งในบทนี้)
- ย6 紇刺星 → “ดาวกาลกิณี”; 湊四合六 → “ลงตัวพอดีเหมาะเจาะ”; 『一來照顧郎中，二來又醫得眼好』 แปลตามตัว “หนึ่งได้อุดหนุนหมอ สองยังรักษาตาหายด้วย”
- ย6 西天 → “แดนตะวันตก” ตามบท 012–015 (ไม่มีแถว GLOSSARY ของ 西天 แยก แต่ 天竺 ห้ามใช้ “ชมพูทวีป”)
- ย8 「這個小長老，倒也家懷」 → “ทำตัวตามสบายเหมือนอยู่บ้านเชียวนะ” (家懷 ไม่เกรงใจ ทำตัวเหมือนบ้านตน) คำตอบสิงเจ่อเล่นต่อคำเดียวกัน
- ย9 「天哪！還吃得有多少哩」 → “ฟ้าเอ๋ย จะเลี้ยงไหวสักกี่ตัวกันเล่า” อ่าน 吃得 เป็นการรับภาระเลี้ยง/ทนได้ ต่อด้วย 「已被他磨慌了」
- ย9 昏去明來 → “ค่ำไปเช้ามา” แปลตามตัว ไม่ตีความว่าขยันทั้งวันทั้งคืน; ภายหลัง ย13 หญิงสาวว่า 昏來朝去 (มาค่ำไปเช้า) ซึ่งเป็นช่วงหลังถูกขัง ขอผู้ตรวจดูว่าควรอ่าน 昏去明來 ว่าออกทำงานแต่มืดหรือไม่
- ย9 燒餅 → “ขนมแป้งอบ”; 斗 → “ถังตวง” ตามแถวเดิม
- ย10 「我為招了他不打緊」 → “ข้ารับมันเป็นเขยนั้นยังไม่เท่าไร แต่…” (不打緊 ไม่สำคัญเท่า)
- ย14 กวี 「凋花折柳勝揌麻」 → “ยิ่งกว่าฟั่นป่าน” (揌 อ่านใกล้ 搓 ฟั่น ไม่ยืนยัน) ขอผู้ตรวจดู; 燕塊 → “ดั่งฝูงนางแอ่น”; 夜叉船 → “เรือของยักษ์”; 長城 → “กำแพงเมืองจีน” ใช้ชื่อที่ผู้อ่านไทยรู้จัก
- ย15 小跌 → “ท่าเหวี่ยงเล็ก”; 漫頭一料 → “ทุ่มข้ามหัว” (S027); 小家子 → “หยาบไม่รู้กาลเทศะ”; 淨桶 “ถังส้วม”; 出恭 “ถ่ายทุกข์”
- ย16 會不得姨夫 → “ออกไปพบพวกพี่เขยไม่ได้” (姨夫 สามีของพี่น้องสาวภรรยา; ย9 บอกว่าพี่สาวสองคนแต่งกับคนในหมู่บ้าน)
- ย16 剛鬣 เชิงอรรถ 018-4 อ้างความหมายคำเรียกหมูในพิธีเซ่นตามตำราพิธีโบราณ (禮記·曲禮下 「豕曰剛鬣」) ขอผู้ตรวจยืนยันแหล่ง
- ย18 磕頭毛臉 → “หน้าผากโหนก หน้าขนดก” อ่าน 磕頭 เป็นลักษณะหัวหน้าผาก ไม่ใช่การโขกศีรษะ; 咨牙徠嘴 → “แยกเขี้ยวยิงฟัน” (S027)
- ย19 咦 → “อ้า!” คำอุทานผู้เล่า
