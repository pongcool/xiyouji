## การตัดสินระหว่างแปล
- ชื่อบท 員外 → “คหบดี” แยกจาก 長者 “เศรษฐี” ที่ใช้กับอนาถบิณฑิกะ (093); 唐長老 “พระเถระถัง” ตามบทก่อน
- ย5, ย7 萬僧不阻 → ป้าย “หมื่นพระไม่กีดกัน”; 虎坐門樓 → “ซุ้มประตูทรงเสือหมอบ” แปลตามตัว
- ย9 龍髯 → “แส้หนวดมังกร” อ่านเป็นแส้ปัดที่แขวนไว้ (掛一柄); 椒粉屏 → “ฉากทาผงพริกหอม”
- ย11 員外媽媽 → “ภรรยาของคหบดี” ตามบริบท (ย18 นางเรียก 我員外 และบุตรเรียก 家母)
- ย12 事林廣記 ถอดเสียงพร้อมเชิงอรรถ 096-1; คำบัณฑิตเอ่ยเพียงสองทวีปตามต้นฉบับ ไม่เติม
- ย15 尺工字樣 → “ทำนองตามตัวโน้ตฉื่อ กง” เชิงอรรถ 096-2; 華嚴 → “คัมภีร์อวตังสกะ” ตามแบบ 楞嚴 ศูรางคมะ; 一二沙門皆一樣 → “สมณะทุกรูปล้วนเหมือนกัน”
- ย18 獻芹 → “ถวายของต่ำต้อยดั่งผักขึ้นฉ่าย” คงภาพ; 寇棟兄弟 → “สองพี่น้องโค่วต้ง” ไม่ระบุใครพี่ใครน้อง
- ย19 「留得在，落得怪」 → “รั้งไว้ได้ก็อยู่ ไม่อยู่ก็ได้แต่คำตำหนิ” อ่านตามบริบทที่ปาเจี้ยอ้างเพื่อให้อยู่ ยังไม่พบคำอธิบายสำนวน ขอผู้ตรวจดู
- ย24 「只有私房路，哪有私房肚」 → “มีแต่ทางเก็บของไว้เป็นส่วนตัว ที่ไหนจะมีท้องเก็บไว้เป็นส่วนตัว”
- ย28 華光行院 → “ศาลหวากวง” (行院 แปลตามบริบทที่ซานจั้งคาดว่ามี 廟祝); 五顯靈官 → “ขุนนางทิพย์อู่เสี่ยน” ถอดเสียงส่วนชื่อ 靈官 ตามแถวเดิม
