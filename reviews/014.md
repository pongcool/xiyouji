## การตัดสินระหว่างแปล
- ย6 行者 → “สิงเจ่อ” + เชิงอรรถ 014-1 ตาม X019; 孫行者 “ซุนสิงเจ่อ”; ย14 「才像個行者」 “จึงจะเหมือนสิงเจ่อ” อาศัยเชิงอรรถ
- ย4 มนตร์หกอักษร → “โอม มณี ปัทเม หูม” ตาม X020 (S023)
- ย11 唐人/糖人/蜜人 → “คนถัง / คนน้ำตาล / คนน้ำผึ้ง” + เชิงอรรถ 014-2 ให้เห็นคำพ้อง; 唐僧 “พระถัง” (ย13 ซานจั้งอธิบายเองว่าใช้ถังเป็นแซ่)
- ย16 ชื่อหกโจรแปลความหมาย (ตาเห็นยินดี ฯลฯ) เพราะชื่อบท 六賊 และประโยค 「喜的喜，怒的怒…」 เล่นกับความหมาย
- ย17 「倒也得些狀告是」 แปลตามไฟล์; wikisource มีวลี 「我就做不到齊天大聖了」 ต่อท้าย (S023) — ถ้าผู้ใช้ให้เติมต้องมีข้อยุติแบบ X017
- ย1 「南無釋迦葉」 → “นโม ศากยะกัสสปะ” คงรูปตามอักษร ยังไม่ยืนยันว่าหมายถึงพระศากยมุนีกับพระกัสสปะหรือพระนามเดียว
- ย24 豎蜻蜓 → “ยืนหัวปักพื้น” (ท่าตั้งหัว); 不忍不捨 → “ใจไม่ไหว ทนไม่ได้”
- ย17 「我可做得白客」 → “ข้าจะทำเป็นคนนอกได้หรือ” อ่าน 白客 ว่าผู้ไม่เกี่ยวข้อง
- 東洋大海 → “ทะเลใหญ่ตะวันออก” ให้ตรงกับ 東洋海 ทะเลตะวันออก (WORLD) ไม่ใช้ “มหาสมุทร” ที่อาจทำให้เข้าใจว่าเป็นอีกที่หนึ่ง (แก้ก่อนส่งตรวจ)
- 綿布直裰 “เสื้อคลุมพระผ้าฝ้าย” / 直裰 “เสื้อคลุมพระ” ไม่ใช้ “จีวร” เพื่อแยกจาก 袈裟
