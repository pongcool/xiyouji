## การตัดสินระหว่างแปล
- ย19 ชื่อเขา/ถ้ำ: ไฟล์ 「金山」「金洞」 ตกอักษร ⿰山兜 (S058) ถอดเสียงตามส่วนเสียง 兜 “เขาจินโตว” “ถ้ำจินโตว” เป็นรูปชั่วคราว ขอผู้ใช้ยืนยันว่าจะใช้ถอดเสียงตามส่วนเสียงนี้ทั้ง 050–052 หรือไม่ (หัวบท 052 ในไฟล์ก็เป็น 金洞)
- ย19 獨角兕大王 → “ราชาซื่อเขาเดียว” ถอดเสียง 兕 พร้อมเชิงอรรถ ไม่ใช้ “แรด” เพราะกวี ย24 「比犀難照水」 แยก 兕 กับ 犀
- ย1 「曹溪任吸呼」 → “ปล่อยเฉาซีให้หายใจเข้าออกตามสบาย” แปลตามตัว ไม่ถอดความเชิงฌาน
- ย11 「倒垂蓮升斗門樓」 → “ซุ้มประตูลายบัวห้อยคว่ำกับคันทวย” อ่าน 升斗 เป็นคันทวยรับชายคา
- ย12 「骷髏有巴斗大」 → “ใหญ่เท่ากระบุงตวงข้าว”
- ย14 「天何蓋焉」 → “ฟ้าจะปิดได้อย่างไร” อ่าน 蓋 = ปิดบัง
- ย15 「我自為人」 → “ตั้งแต่ข้าเป็นคนมา” คงตามตัว
- ย20 「把這齋飯倒與他，將這空缽盂自家收拾」 แล้วตาเฒ่า 「接了缽盂」 → แปล “เทอาหารเจให้เขา ส่วนบาตรเปล่าจะเก็บไว้เอง … รับบาตร” คงลำดับตามตัว ข้อความดูขัดกันเล็กน้อย (สิงเจ่อตั้งใจเก็บบาตร แต่ตาเฒ่ารับไป) ขอผู้ตรวจดู
- ย24 「全無喘月犁雲用」 → “ไม่มีประโยชน์อย่างหอบเพราะจันทร์หรือไถเมฆ” และ 「比犀難照水」 อธิบายในเชิงอรรถ 050-2
- ย27 「果然是一個偷丹的魔頭」 → “สมเป็นหัวหน้ามารที่ขโมยโอสถจริง ๆ” แปลตามตัว ไม่อธิบายว่าเป็นการบอกใบ้ที่มาของ C151
