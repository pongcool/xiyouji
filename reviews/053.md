## การตัดสินระหว่างแปล
- ชื่อบท 「禪主吞餐懷鬼孕　黃婆運水解邪胎」 → “เจ้าแห่งฌานกลืนอาหารตั้งครรภ์ผี ยายเหลืองขนน้ำแก้ครรภ์ชั่ว” 黃婆 ตามแถว 黃婆 (023) คงภาพ ไม่ถอดว่าเป็น C035
- ย1 「空勞水火無愆」 → “น้ำไฟเหนื่อยเปล่ามันไม่เป็นอะไร” อ่าน 無愆 ว่าปีศาจไม่เสียหาย ขอผู้ตรวจดู
- ย2 การเล่นคำ 圈: 「不出圈痕」 “ไม่ออกนอกรอยวง” (วงที่ C001 ขีดใน 050) กับ 「受別人的圈子」 “โดนวงห่วงของคนอื่น” และ 八戒 「又有個圈子」 “มีวงอีกอันล่ะ” ใช้ “วง” ร่วมเพื่อคงมุก
- ย5 「橄堂油漆彩」 → “ห้องเรือทาน้ำมันลงสี” อ่าน 橄堂 เป็นห้องในเรือ (wikisource ตรงไฟล์ ไม่ได้เปิดสแกน)
- ย10 「館驛」 → “เรือนรับรองหลวง” ตามแถว 館驛; 國王 → “กษัตริย์”
- ย11 「摧陣疼」 → “เจ็บท้องคลอด” (摧 = 催); 「漿包」 → “ถุงน้ำคร่ำ”
- ย17 「怒從心上起，惡向膽邊生」 → “โทสะพลุ่งขึ้นจากใจ ความร้ายผุดขึ้นข้างดี”; 「眉菂豎」 → “คิ้วตั้งชัน” (S061); 「鐏利杆長」 → “ส้นด้ามคมด้ามยาว”
- ย19 「孫悟空憊懶，將他害了」 → “ซุนอู้คงอันธพาล ทำร้ายเขา”
- ย20 คำพรรณนาศึก 「那一個為侄亡身不與泉」 → “เพราะหลานเสียตัวจึงไม่ให้น้ำบ่อ” (C129 ไม่ได้ตาย อ่าน 亡身 ว่าเสียอิสระ); 「蜋捕蟬」 → “ตั๊กแตนตำข้าวจับจั๊กจั่น”
- ย26 「決有慢他師之心」 → “ใจมันต้องหย่อนลงเพราะห่วงอาจารย์แน่” ความกำกวม (慢 = ใจหย่อน/ไม่ใส่ใจ) ขอผู้ตรวจดู
- ย27 「一處賭安休」 → “ที่เดียวกันพนันว่าใครจะได้สงบ”
- ย29 กวีหลอมโอสถ 真鉛/真汞/真水/土母/心君/旁門 แปลตามตัวตามแถวเดิม ไม่ถอดรหัสว่าใครคือ 土母
- ย30 「幾時占房的」 → “เข้าห้องคลอดเมื่อไร”; ย31 「坐月子」 → “อยู่ไฟ”
