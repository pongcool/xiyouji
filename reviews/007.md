## การตัดสินระหว่างแปล
- ชื่อบท/ย2–ย4 八卦爐 → “เตาปากว้า” ถอดเสียง 八卦 พร้อมเชิงอรรถ ไม่ใช้รูปจีนถิ่น “โป๊ยก่วย”
- ย1 東君 → “เทพแห่งวสันต์” (東君 ใช้ได้ทั้งเทพฤดูใบไม้ผลิและเทพตะวัน) ให้ผู้ตรวจดู
- ย3 火煼紅 (S014) → “คั่วสองตาจนแดง”
- ย7–ย22 如來 → “พระตถาคต”, 佛祖 → “พระพุทธองค์”, 阿儺/迦葉 → พระอานนท์/พระกัสสปะ ตามคำพุทธไทย (แนวเดียวกับ 地藏 → กษิติครรภ)
- ย5 靈官 → “ขุนนางทิพย์”; 佑聖真君/翊聖真君 แปลความหมาย
- ย10 不當人子 → “บาปนัก” (สำนวน = 罪過 ไม่สมควร) ไม่แปลตามตัวอักษร
- ย10 皇帝輪流做，明年到我家 → “จักรพรรดิผลัดกันเป็น ปีหน้าถึงบ้านข้า” ไม่ใช้ “ฮ่องเต้” (รูปจีนถิ่น)
- ย11 又不莊尊 → “ยังไม่รู้จักสำรวม”; ย12 尿精猴子 → “เจ้าลิงขี้เยี่ยว”
- ย14 天蓬、天佑 ถอดเสียงเป็นชื่อตำแหน่ง (เทียนเผิง/เทียนโย่ว) ต้องตรวจเมื่อพบ 天蓬元帥
- ย16 請眾仙眾佛俱成功 → “ได้เชิญเซียนทั้งหลายพุทธะทั้งหลายล้วนมาสร้างผลงาน” ประโยคกำกวม (ใครเป็นผู้ “成功”) ให้ผู้ตรวจดู
- ย21 唵嘛呢叭吽 → “โอม มณี ปัท หูม” ถอดตามอักษรห้าตัวในไฟล์ (唵 โอม, 嘛呢 มณี, 叭 ปัท, 吽 หูม) ไม่เติม 咪 “เม” จากฉบับเทียบเพราะเปลี่ยนข้อความ ต้องมีข้อยุติผู้ใช้ (XO005)
