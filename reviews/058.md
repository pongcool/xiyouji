## การตัดสินระหว่างแปล
- ชื่อบท 「二心攪亂大乾坤　一體難修真寂滅」 → “สองใจปั่นป่วนฟ้าดินใหญ่ กายเดียวยากบำเพ็ญความดับสงบแท้” (寂滅 แปลความหมาย “ความดับสงบ” ไม่ใช้ “นิพพาน” ซึ่งแคบกว่าบริบทชื่อบท) ขอผู้ตรวจดู
- ย1 「朔腮別土星」 → “แก้มตอบ จมูกงุ้ม” (土星 ในตำราดูหน้าคือจมูก; 別 อ่านว่าบิด/ยื่น) ขอผู้ตรวจดู
- ย2 กวีศึก 「混元一氣齊天聖」 → “มหาปราชญ์เสมอฟ้าผู้เป็นปราณหนึ่งแห่งปฐมธาตุ” ตามแถว 混元一氣; 「久煉千靈縮地精」 → “ปีศาจย่อแผ่นดินที่หลอมพันวิญญาณมานาน”; 「隨心鐵桿兵」 → “อาวุธคานเหล็กตามใจ”
- ย4 「拔刀相助」 แปลตามสำนวน “ชักดาบเข้าช่วย” แม้ C035 ใช้ไม้เท้า
- ย8 คำ C001 ถูกตัดกลางด้วย 「如此如彼，把前情備陳了一遍」 แล้วต่อคำพูด คงโครงตามต้นฉบับ; ตัด “…” ตาม S065
- ย12 「念念那話兒」 → “ท่องไอ้นั่นดู” ตามแถว 那話兒 (C035 เลี่ยงคำว่าคาถา)
- ย16 「各執笏」 → “ต่างถือป้ายเข้าเฝ้า”
- ย17 「諦聽」 ถอดเสียง “ตี้ทิง” พร้อมเชิงอรรถความหมาย (ชื่อสัตว์ ไม่แปลเป็นกริยา); ประโยคคุณสมบัติยาว 「將四大部洲…可以照鑒善惡，察聽賢愚」 แบ่งเป็นสองประโยค
- ย18 「靈鷲仙山」 → “เขาเซียนคิชฌกูฏ” (คำพุทธไทยของ 靈鷲 Gṛdhrakūṭa)
- ย18 ธรรมเทศนา 「不有中有，不無中無…名為照了，始達妙音」 แปลตามโครงคู่ตรงข้ามทีละวลี ไม่ตีความเพิ่ม ขอผู้ตรวจดู
- ย21 「通臂猿猴」 → “วานรแขนทะลุ” แยกจาก 通背猿猴 “วานรแขนทะลุหลัง” (001/003) ตามอักษร; 「六耳獼猴」 → “ลิงวอกหกหู” ตามแถว 獼猴王
- ย22 「如來不忍」 → “พระตถาคตทรงสลดพระทัย”; 「至今絕此一種」 → “จนบัดนี้ลิงชนิดนี้ก็สูญสิ้นไป”
- ย22 「還俗」 → “สึกกลับไปเป็นฆราวาส”
