## การตัดสินระหว่างแปล
- ย5 รายชื่อกลุ่มดาว: ต้นฉบับใส่ 參 ในเจ็ดกลุ่มตะวันออก (ปกติเป็น 心) และเรียกชุด 斗牛女虛危室壁 ว่าตะวันตก (ปกติเป็นทิศเหนือ) สแกนหน้า 659 ตรงไฟล์ (S059) จึงแปลตามตัว ไม่แก้และไม่ใส่เชิงอรรถชี้ว่าผิด
- ย3 「我老孫一生是這口兒緊些，才尋的著個頭兒」 → “เหล่าซุนชั่วชีวิตนี้ก็ปากไม่ยอมลดละอย่างนี้แหละ จึงหาต้นตอเจอ” อ่าน 口兒緊 เป็นพูดรุกไล่ไม่ปล่อย ตอบคำ 放刁 ขอผู้ตรวจดู
- ย5 可韓丈人真君 → “สัจเทพผู้อาวุโสเข่อหาน” 丈人 คำยกย่อง; 三微垣 → “เขตกำแพงดาวทั้งสาม” แปลตามโครง 三垣; 七政/四餘 แปลความ “เจ็ดดาวประธาน/สี่ดาวเศษ” ถอดเสียง 炁 孛
- ย8, ย12 雷㨝 → “ลิ่มสายฟ้า” อ่าน 㨝 = 楔; 錠死 → “ตอก…ให้ตาย” (錠 = 釘)
- ย11 「我就是那聖僧的魔頭哩」 → “ข้านี่แหละคือมารร้ายของพระศักดิ์สิทธิ์นั่น” คงความกำกวมแบบอวด
- ย12 อาวุธชุดนี้ต่างจาก 004 (砍妖劍/斬妖刀 สลับ, 降魔杵) แปลตามตัวด้วยรูปเดิม 斬→ฟัน 砍→สับ
- ย16 「與他眺戰」 → “ตั้งรอรบกับมัน” อ่าน 眺 = 挑 ตามบริบทเตรียมโจมตี ไม่ได้เปิดสแกนจุดนี้ ขอผู้ตรวจดู
- ย17 「因欺禪性」 → “รังแกภาวะแห่งฌาน”; 世尊 “พระผู้มีพระภาคเจ้า” ตามแถว 529
- ย18 「說甚麼甯戚鞭牛」 แปลตามตัว “หนิงชีหวดวัว” เชิงอรรถให้เพียงประวัติหนิงชีเลี้ยงวัว ไม่อธิบายว่าเกี่ยวกับไฟอย่างไรเพราะไม่พบหลักฐาน
- ย23 「一勺之多，果然不測」 → “น้ำเพียงทัพพีหนึ่ง แต่หยั่งไม่ถึงจริง ๆ”
- ย25 「筋䯞子拳頭」 → “หมัดผอมเห็นแต่เอ็น”; 「怎麼稱得個鎚子起」 → “จะนับเป็นค้อนได้อย่างไร”
- ย27–ย28 圈套 → “ห่วงกล” คงการเล่นคำห่วง/กับดัก; 套子 → “ห่วงสวม”
- ย28 「若要行偷禮」 → “ถ้าจะทำพิธีขโมย” คงคำ 禮 เชิงเย้า
- ย29 「手足比毛更奘」 → “มือเท้าหนากว่าเส้นขนเพียงนิด” (奘 = หนา/ใหญ่); 「稱來剛壓定盤星」 → “ชั่งดูก็แค่กดขีดแรกบนคานตาชั่ง”
- ย30 青磁 → “ศิลาดล”; 羊酪椰醪 → “เหล้านมแพะเหล้ามะพร้าว”
