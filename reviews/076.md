## การตัดสินระหว่างแปล
- ชื่อบท 心神居舍 → “ใจและจิตสถิตในเรือน”; 魔歸性 → “มารคืนสู่ภาวะ” (性 ภาวะ ตามชื่อบท 033/035); 怪體真 → “ร่างปีศาจแท้จริง” ไม่ถอดรหัสว่าหมายถึงใคร
- ย1 支吾 → “อาละวาด” ตามรอยต่อ 075:ย31 ที่สิงเจ่อเมาอาละวาดในท้อง
- ย6 「喉嚨裏又㮇㮇的惡心」 → “ในคอหอยก็ระคายคลื่นไส้” 㮇㮇 ยังไม่พบคำอธิบาย แปลตามบริบทเชือกค้างในคอ ขอผู้ตรวจดู
- ย6 掩樣的法兒 → “วิชาอำพราง” (ทำให้ดูเหมือนยังผูก)
- ย7 棺材座子──專一害人 → “แท่นรองโลงศพ—มีแต่จะทำร้ายคนอย่างเดียว” คงคำเปรียบ ไม่ขยาย
- ย10 「住後就跑」 อ่าน 住 เป็น 往 ตามบริบท “วิ่งหนีกลับ” (wikisource ตรงไฟล์ ไม่ได้เปิดสแกน เพราะความชัด)
- ย11 「左右是捨命之材」 → “อย่างไรข้าก็เป็นตัวที่สละทิ้งได้อยู่แล้ว” อ่านเป็นคำประชดตนเองของสิงเจ่อ
- ย14 勾司人 → “คนจากกรมจับวิญญาณ”; 五閻王 → “พญายมองค์ที่ห้า”; ข้อความ 「咄！你銀子在那裏？」 แยกจากความคิดในใจ 暗笑道 ด้วย “แล้วว่า”
- ย22 紅沙 → “วันร้ายหงซา”; ย23 泰極否還生 → “รุ่งเรืองถึงที่สุด ความอับเฉาก็กลับเกิด” แปลความหมายชื่อเกวี้ย
- ย26 主僧 → “พระผู้เป็นใหญ่” เลี่ยง “พระประธาน”
