## การตัดสินระหว่างแปล
- ย3–ย10 父王 → “ท่านพ่อ” ไม่ใช้ “เสด็จพ่อ” ของแถว 國王/父王 เพราะ C129 เป็นปีศาจ ไม่ใช่ราชสำนักมนุษย์ (ADDRESS_TERMS); ใช้แบบเดียวกันเมื่อ C025 เรียก C015 ย18–ย19 ขอผู้ตรวจดูว่าควรแยกหรือไม่
- ย4 「往山腰裏搠個窟窿，連山都掬了去」 → “แทงทะลุกลางไหล่เขาเป็นโพรง แล้วยกภูเขาไปทั้งลูก”
- ย7 「三辛逢初六」 → “สามวันซินกับขึ้นหกค่ำ” แปลตามตัว (สามวันซินในเดือน รวมวันที่หก เป็นสี่วัน); 「酉不會客」 → “วันโหย่วไม่รับแขก”
- ย9 「不似這廝剋剝」 → “ไม่เคยเจอตัวไหนจับผิดละเอียดเหมือนไอ้นี่”; 「信口捏膿」 → “ปั้นน้ำเป็นตัว”
- ย14 กวีเต่า 幫泥 ถอดเสียง “ปังหนี” เพราะความหมายไม่ชัดและสแกนซีด (S050); 「曾元卜」 → “เคยใช้เสี่ยงทายใหญ่” อ่าน 元 = ใหญ่/ต้น ตามประเพณีใช้กระดองเต่าเสี่ยงทาย
- ย16–ย18 「善財龍女」 → “ธิดามังกรซ่านไฉ” อ่านเป็นบริวารผู้เดียว เพราะพระโพธิสัตว์พูดต่อว่า 「你見我這龍女貌美」 และสั่งงานครั้งละหนึ่ง (劈一瓣蓮花, 閉了洞門); อีกทางคือ “ซ่านไฉกับธิดามังกร” สองตน ขอผู้ตรวจดู ไม่เดาความสัมพันธ์กับ 善財童子 ที่ C029 ตั้งให้ C129 ใน ย28
- ย16 「教我這善財也難捨」 → “ก็ทำให้ซ่านไฉของอาตมายากจะสละให้ไปด้วย” คงชื่อ + เชิงอรรถ 042-1 การเล่นคำ 善財 ทรัพย์อันดี
- ย17 「走了硝」 → “หนังฟอกจะเสีย” (ดินประสิวที่ใช้ฟอกหนังหลุดเมื่อเปียก) ทางเดียวกับแถว 老走硝
- ย21 「滿海長金連」 → “เต็มทะเลบัวทองงอกต่อกัน” และ 「萬疊波濤連四野」 → “คลื่นหมื่นชั้นต่อเนื่องไปทั่วสี่ทิศ” (S050)
- ย22 「迷」 字 → อักษร “หลง” แปลความหมาย ไม่ถอดเสียง
- ย28 「太山壓頂…三個頂搭，挽起三個窩角揪兒」 → “โกนเป็นทรงเขาไท่ซานทับยอด เหลือผมไว้สามหย่อม เกล้าเป็นจุกม้วนสามจุก”
