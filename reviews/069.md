## การตัดสินระหว่างแปล
- ชื่อบท 心主 → “เจ้าแห่งใจ” คงภาพตามชื่อบท ไม่ระบุว่าเป็นสิงเจ่อ
- ย1 經閉 → “ทางเลือดลมปิดกั้น” 經閉 โดยทั่วไปหมายถึงประจำเดือนขาด แต่ผู้ป่วยเป็นพระราชา จึงเลือกความกว้างว่าเส้นทางเลือดลมอุดตัน ขอผู้ตรวจดูว่าควรคงความตามอักษร (ระดูขาด) หรือไม่
- ย1 四氣、五鬱、七表、八裏、九候 แปลตามตัวเลขและคำ ไม่อธิบายรายการในตำราแพทย์
- ย1, ย18, ย19 龍床 → “พระแท่นบรรทม” เพราะเป็นที่ประทับในตำหนักบรรทมขณะประชวร ตามหมายเหตุแถว 583 (R068-C14)
- ย4 閣下 → “เหล่ามหาเสนาบดี” และ ย6 閣老 → “มหาเสนาบดี” ถือว่า 閣下 ในที่นี้หมายถึงขุนนางฝ่ายหอ (閣) ที่ ย6 ระบุว่ามีสามคนปรนนิบัติ
- ย8 大黃 → “โกฐน้ำเต้า”, 巴豆 → “สลอด” ใช้ชื่อไทยของพืชชนิดเดียวกัน (Rheum, Croton tiglium) เพราะเป็นตัวยาจริงในฉากปรุง ไม่ใช่กวีซ้อนความแบบ 028
- ย9 起奪人 → “เอาเปรียบคนเขา” ความของ 起奪 ยังไม่พบนิยามตรงคำ อ่านจากบริบทว่าปาเจี้ยว่าการเรียกยามากแต่ใช้สองตำลึงเป็นการรีดเอาของ
- ย9 百草霜 → “น้ำค้างแข็งร้อยหญ้า” คงชื่อตัวยาเพราะข้อความอธิบายเองว่าเป็นเขม่ากระทะ
- ย10 亡人 (ปาเจี้ยเรียกม้า) → “เจ้าผีตาย” คำด่าเชิงบ่น
- ย14 困龍鬚 → “หนวดมังกรติดหล่ม” ความ 困龍 ไม่ยืนยัน (มังกรที่ติดอยู่/จนตรอก) แปลตามตัวอักษร
- ย14 緊水負的鯉魚 → “ปลาไนที่ว่ายทวนน้ำเชี่ยว” อ่าน 負 ว่าทวน/ต้าน
- ย16 輔星/弼宿 → “ดาวผู้ช่วยซ้าย/ดาวผู้ช่วยขวา” ตามแถว 左輔、右弼 ให้ตรงกับตำแหน่งยืนซ้ายขวา
- ย21 คำพรรณนางานเลี้ยง แบ่งเป็นวรรคกวี เพราะสแกนหน้า PDF 897 พิมพ์แยกวรรคแบบกลอน และเป็นวรรคคู่สัมผัส; 斗糖龍纏列獅仙，餅錠拖爐擺鳳侶 แปลตามภาพขนมน้ำตาลปั้น ไม่ยืนยันชื่อขนมแต่ละชนิด
- ย22 三寶鍾/四季杯 → “จอกไตรรัตน์/จอกสี่ฤดู” พร้อมเชิงอรรถ 069-2
- ย25 正宮/東宮/西宮 และ 金聖宮/玉聖宮/銀聖宮 → “วังเอก/วังตะวันออก/วังตะวันตก” และถอดเสียง “จินเซิ่งกง/อวี้เซิ่งกง/อิ๋นเซิ่งกง” ทั้งสมัญญา เพราะใช้เป็นชื่อเรียกบุคคลต่อเนื่องถึง 070 (聖宮娘娘 “พระนางเซิ่งกง”) เชิงอรรถ 069-4 ให้ความหมาย; ขอผู้ตรวจดูทางเลือกนี้
- ย25 賽太歲 → “ไซ่ไท่ซุ่ย” ถอดเสียงตามแบบชื่อราชาปีศาจ (หวงเหมย เซิ่งอิง) พร้อมเชิงอรรถ 069-6 ความหมาย “ผู้เหนือกว่าไท่ซุ่ย”
