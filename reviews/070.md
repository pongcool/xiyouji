## การตัดสินระหว่างแปล
- ชื่อบท 紫金鈴 → “กระดิ่งทองม่วง” ตามแถว 紫金 (บาตรทองม่วง)
- ย1 擦著些兒神氣泄 → “เฉียดถูกเพียงนิดก็สิ้นกำลังวังชา” ถือว่า 神氣 เป็นของฝ่ายอาวุธสามัญ
- ย3 皇帝 (ผู้เล่า) → “จักรพรรดิองค์นั้น” คงคำตามต้นฉบับ ไม่เปลี่ยนเป็นพระราชา
- ย4 夜不收軍馬 → “พลม้าสอดแนม”
- ย4 กวี 烏兔 → “กาตะวันกับกระต่ายจันทร์”; 長江百十數 → “แม่น้ำใหญ่ร้อยสิบสาย” เพราะเป็นพหูพจน์ ไม่ใช่ชื่อแม่น้ำฉางเจียง; 凌雲渡 ถอดเสียง “ท่าหลิงอวิ๋น” (ยังไม่พบในบทก่อน)
- ย9 攢火的鷂子 → “เหยี่ยวพุ่งฝ่าไฟ”
- ย10 猛蟲兒 → “ริ้น” อ่าน 猛 เป็น 蠓 (แมลงตัวเล็กที่บินไปเกาะห่อหนังสือได้) ขอผู้ตรวจดู
- ย10 頂缸 → “รับเคราะห์แทน” นางกำนัลถูกฆ่าแทนพระนาง ความ “รับแทนความผิด” ตามแถว 573 ไม่เข้ากับบริบท
- ย12 那話兒 → “คนนั้น” สิงเจ่อเลี่ยงเอ่ยถึงพระนาง ไม่ใช้ “ไอ้นั่น” ตามแถว 386 เพราะผู้ถูกกล่าวถึงเป็นพระมเหสี
- ย13 有來有去 → “มีมามีไป” แปลความหมายเพื่อคงมุก 有去無來 “ตีจนมีไปไม่มีมา”; ป้าย 五短身材 → “รูปร่างเตี้ยป้อม”, 扢撻臉 → “หน้าตะปุ่มตะป่ำ” ตามแถว 扢撻藤
- ย16 長亭共短亭 → “ศาลาส่งลาไกลและใกล้” พร้อมเชิงอรรถ 070-1; 為壓寨 → “ไปเป็นนายหญิงค่ายโจร” ตามแถว 壓寨夫人
- ย17 陛下在邇，何以惱為 → “เรื่องก็ใกล้แค่เอื้อม จะกลุ้มไปไย” อ่าน 在邇 ว่าการช่วยพระนางอยู่ใกล้แล้ว ขอผู้ตรวจดู
- ย17 端午 → “ตวนอู่” คงคำต่างจาก 端陽 ตวนหยาง ใน 069 ตามต้นฉบับ
- ย18, ย29 獺象 → “ช้างใหญ่” ตามแถว 賴象 (635) ความของ 獺 ไม่ยืนยัน; 熊師 “นายทัพหมี”, 豹頭 “หัวหน้าเสือดาว”, 猩猩 “อุรังอุตัง”
- ย21 รายการอาวุธ 銃鉋 → “ปืนไฟ เครื่องยิง” อ่าน 鉋 เป็น 砲; 䩺鞋 → “รองเท้าบู๊ต”
- ย24 接喏 → “คำนับละ” คำทักแบบไม่เป็นพิธีที่พระนางถือว่าหยาบ
- ย27 太宰 → “มหาอำมาตย์”
- ย28 血食 → “เนื้อสดคาวเลือด” อาหารของปีศาจ ไม่ใช่เครื่องเซ่นตามแถว 640
