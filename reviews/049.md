## การตัดสินระหว่างแปล
- ย2 「打個躘踵，得故子把行者往前一摜」 → “ทำเป็นสะดุดเซ จงใจเหวี่ยง” อ่าน 得故子 เป็นจงใจ (故) ตามที่ปาเจี้ยตั้งใจแกล้ง
- ย5 「演了一會」 → “ใคร่ครวญอยู่ครู่หนึ่ง” อ่าน 演 เป็นคิดทบทวน (推演)
- ย8 「敢稱靈顯大王威」 → “กล้าอ้างอำนาจราชาผู้ศักดิ์สิทธิ์สำแดง” กวีใช้ 靈顯 ไม่ใช่ 靈感 จึงแปลตามตัว ไม่บังคับเป็นชื่อ C148
- ย8 「響似三春驚蟄雷」 → “ดั่งฟ้าร้องปลุกแมลงจำศีลกลางวสันต์สามเดือน” แปลความ 驚蟄 แทนการถอดเสียงสารท ไม่ใส่เชิงอรรถ
- ย10 「遜金妝來似蟒形」 → “ทองเนื้อรองประดับไว้” แปลตามตัว 遜金 (สแกนตรง) ความยังไม่ชัด อาจเป็นรูปแปรของ 滲金 ปิดทอง ยังไม่พบหลักฐาน ขอผู้ตรวจดู
- ย15 「打個花」 → “ทำท่าหลอกทีหนึ่ง” อ่านเป็นท่าสะบัดหลอกก่อนหนี
- ย17 「虧了你識俊」 → “ดีที่ท่านรู้ทัน” อ่าน 識俊 = 識時務
- ย22 「性急能鵲薄」 → “ใจร้อนจนไม่สำรวม” อ่าน 鵲薄 ใกล้ 輕薄 (สแกนตรงไฟล์) ความไม่แน่นอน ขอผู้ตรวจดู
- ย24 「重置家事」 → “มาจัดการงานบ้านอีกแล้ว” ตามที่สิงเจ่อเห็นพระโพธิสัตว์เหลาตอก
- ย28 「陳清兄弟」 → “พี่น้องเฉินชิง” คงรูปจีน (C144/C145)
- ย29 「九助靈機號水仙」 → “เก้าประการเกื้อกลไกวิเศษ” แปลตามตัว (สแกนตรง) ความยังไม่ชัด; 「千紀壽」 → “พันกาล” ไม่ระบุ 紀 สิบสองปี
- ย31 「但歪一歪，不成功果」 → “ถ้าเอียงสักนิด ก็ขอไม่สำเร็จผลบุญ” อ่านเป็นคำสาบานตนของ C150
