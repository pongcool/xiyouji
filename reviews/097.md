## การตัดสินระหว่างแปล
- ชื่อบท 金酬外護遭魔蟄 → “ทองตอบแทนผู้อุปถัมภ์ภายนอกกลับถูกมารต่อย” (外護 ศัพท์พุทธ ฆราวาสผู้อุปถัมภ์); 聖顯幽魂救本原 → “ปราชญ์สำแดงดวงวิญญาณช่วยกู้ต้นเดิม” ใช้ “สำแดงวิญญาณ” ตามแถว 顯魂 ไม่ระบุว่า 聖 คือใครเกินคำ; ขอผู้ตรวจดูการอ่าน 聖顯幽魂
- ย1 拐子 (อาวุธ) → “ไม้ศอก”; 蒺藜 → “ลูกเหล็กหนาม”; 撩陰一腳 → “เตะเข้าหว่างขา”
- ย2 ข้อความคำร้องวางเป็นร้อยกรองสองวรรคตามรูปคู่ห้า/เจ็ดคำ
- ย3 龔黃/卓魯 ใส่เชิงอรรถ 097-1; 黃堂 → “หอว่าการเหลือง”
- ย11 腦箍 → “ห่วงบีบหัว” แยกจาก 緊箍 “ห่วงรัด”; 「一似大海吞舟」 → “ดั่งทะเลใหญ่กลืนเรือ” แปลตามภาพ
- ย12 都下陳少保 → “ท่านเส้าเป่าเฉินจากเมืองหลวง”; 轄床/滾肚/敵腦/攀胸 → “เตียงตรึง สายคาดท้อง สายกดหัว สายรั้งอก” แปลตามหน้าที่
- ย14 「做個劈著」 → “ตัดสินแบ่งให้” ตามบริบทแบ่งของ
- ย15 寇大官 → “พี่โค่ว” ตามผู้พูดที่เป็นเพื่อนเรียนรุ่นพี่; 穿針兒 ถอดเสียง “ชวนเจินเอ๋อร์” ตามแบบชื่อบุคคล ไม่ใส่เชิงอรรถ
- ย17 「綽著經兒」 → “ฉวยโอกาส”; 甲科 → “สอบได้อันดับต้น”
- ย18 浪蕩遊神 → “เทพตระเวนเร่ร่อน” ตามแถว 遊神
- ย24 一紀 → “หนึ่งรอบ” ข้อความเดียวกันระบุ “สิบสองปี” จึงไม่เติมคำอธิบาย
