## การตัดสินระหว่างแปล
- ชื่อบท 「二調芭蕉扇」 → “เล่นเล่ห์ชิงพัดใบกล้วยครั้งที่สอง” ตาม 059

- ย1 「我在那裏？」 → “ข้าอยู่ที่ไหนมา” (ปฏิเสธว่าไม่เคยอยู่ที่นี่)
- ย2 「玉面公主」 → “เจ้าหญิงหน้าหยก” แปลความหมายแบบ 鐵扇公主 “เจ้าหญิงพัดเหล็ก”; 「倒陪家私，招贅為夫」 → “ยอมออกทรัพย์สมบัติเอง รับเขาแต่งเข้าบ้านเป็นสามี”
- ย4 「高髻堆青𢷑碧鴉」 อักษร 𢷑 หายาก แปลตามความรวม “มวยผมสูงกองดำขลับปักเขียวดั่งขนกา”; 「湘裙」 → “กระโปรงแพรเซียง”; 「錦江滑膩」 → “ผิวเนียนดั่งน้ำแม่น้ำจิ่น”
- ย6 「亂𤜱金蓮」 อักษร 𤜱 หายาก แปลตามความ “เท้าน้อยก้าวสะเปะสะปะ”; 「陪錢嫁漢」 → “ออกเงินแต่งสามี”

- ย10 「朋友妾，不可滅」 → “เมียน้อยเพื่อน ห้ามหมิ่น” (滅 = ดูแคลนเหยียบย่ำ); 「即時完璧」 → “จะคืนให้ครบถ้วนทันที”; 「皆傍寸」 → “ต่างสูสีห่างกันไม่ถึงชุ่น”
- ย13 「青頭鱸妓」 → “นางคณิกาปลากะพงหัวเขียว”; 「鳥篆之文」 → “อักษรรอยเท้านก”; 「宮商」 → “เสียงกงเสียงซาง”
- ย15 「官受橫行介士」 → “ได้ตำแหน่งทหารเกราะเดินขวาง” (เล่นคำปูเดินขวาง)
- ย18 「「牛王」道」 ผู้เล่าใส่เครื่องหมายคำพูดเพื่อบอกว่าเป็นตัวปลอม → ‘ราชาวัว’ ว่า

- Codex เสนอ: “ไม่เห็นแพ้ชนะ ต่างสูสีกัน” ตามบริบท 不分勝負 ใน ย11; ยังไม่รับรองว่าตัวบทกำหนดระยะประมาณหนึ่งชุ่น การเก็บอักษร 寸 ไม่จำเป็นต้องหมายถึงเก็บหน่วยความยาว หากคำนี้ใช้ความหมายอื่น
- หลักฐานสแกน: หน้า PDF 780 [ภาพ](evidence/R060-C4/p780-verse.png) ตรง 皆傍寸; เปิดภาพตรวจซ้ำ 2026-11-16
- หลักฐานเพิ่ม: [漢典 หัวคำ 寸](https://zdic.net/hans/寸), ส่วน 詳細解釋 → 動 ระบุ “協助” และยกวรรคนี้เป็นตัวอย่างโดยตรง (เปิด 2026-11-16). เป็นหลักฐานว่ามีผู้ตี 寸 ในวรรคนี้เป็นกริยา ไม่ใช่หลักฐานยืนยันความหมาย 傍寸 ทั้งคำ; ยังไม่เสนอแปลว่า “ช่วยเหลือกัน” เพราะบริบทเป็นการต่อสู้สองฝ่าย ทั้งนี้ [หัวคำ 傍](https://zdic.net/hans/傍) ให้นัยใกล้/ชิด แต่ไม่ได้ยืนยันความหมายประมาณหนึ่งชุ่นในวรรคนี้
- ให้ผู้ใช้เลือก: (ก) ใช้ “ไม่เห็นแพ้ชนะ ต่างสูสีกัน” ตามข้อเสนอ Codex โดยเก็บข้อจำกัดศัพท์ไว้ในรายงาน; (ข) คง “ไม่เห็นแพ้ชนะ ต่างสูสีใกล้กันราวชุ่นเดียว” ตามผู้แปลเป็นรูปชั่วคราวจนพบหลักฐานเพิ่ม ระหว่างรอไม่เปลี่ยนคำแปล และยังไม่ปิด R060-C4
