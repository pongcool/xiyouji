## การตัดสินระหว่างแปล
- ชื่อบท 「二調芭蕉扇」 → “เล่นเล่ห์ชิงพัดใบกล้วยครั้งที่สอง” ตาม 059
- ย1 「被顯聖擒了」 → “ถูกเทพผู้สำแดงฤทธิ์จับได้” (顯聖 ย่อจาก C026; ไม่เติมชื่อเอ้อร์หลาง)
- ย1 「我在那裏？」 → “ข้าอยู่ที่ไหนมา” (ปฏิเสธว่าไม่เคยอยู่ที่นี่)
- ย2 「玉面公主」 → “เจ้าหญิงหน้าหยก” แปลความหมายแบบ 鐵扇公主 “เจ้าหญิงพัดเหล็ก”; 「倒陪家私，招贅為夫」 → “ยอมออกทรัพย์สมบัติเอง รับเขาแต่งเข้าบ้านเป็นสามี”
- ย4 「高髻堆青𢷑碧鴉」 อักษร 𢷑 หายาก แปลตามความรวม “มวยผมสูงกองดำขลับปักเขียวดั่งขนกา”; 「湘裙」 → “กระโปรงแพรเซียง”; 「錦江滑膩」 → “ผิวเนียนดั่งน้ำแม่น้ำจิ่น”
- ย6 「亂𤜱金蓮」 อักษร 𤜱 หายาก แปลตามความ “เท้าน้อยก้าวสะเปะสะปะ”; 「陪錢嫁漢」 → “ออกเงินแต่งสามี”
- ย7 「山妻」 → “เมียบ้านป่า” (คำถ่อมเรียกภรรยาตน คงภาพ 山); 「內無一尺之童」 → “ข้างในไม่มีเด็กผู้ชายแม้สูงฉื่อเดียว”
- ย9 「牛聖嬰」 → “หนิวเซิ่งอิง” (牛 เป็นแซ่ที่ C014 ใช้กับลูก)
- ย10 「朋友妾，不可滅」 → “เมียน้อยเพื่อน ห้ามหมิ่น” (滅 = ดูแคลนเหยียบย่ำ); 「即時完璧」 → “จะคืนให้ครบถ้วนทันที”; 「皆傍寸」 → “ต่างสูสีห่างกันไม่ถึงชุ่น”
- ย13 「青頭鱸妓」 → “นางคณิกาปลากะพงหัวเขียว”; 「鳥篆之文」 → “อักษรรอยเท้านก”; 「宮商」 → “เสียงกงเสียงซาง”
- ย15 「官受橫行介士」 → “ได้ตำแหน่งทหารเกราะเดินขวาง” (เล่นคำปูเดินขวาง)
- ย18 「「牛王」道」 ผู้เล่าใส่เครื่องหมายคำพูดเพื่อบอกว่าเป็นตัวปลอม → ‘ราชาวัว’ ว่า
- ย19 「妻者，齊也」 → “ภรรยาคือผู้เสมอกัน” (เล่นเสียง 妻/齊 ไทยรักษาไม่ได้ ไม่ใส่เชิงอรรถ); 「莫忘結髮」 → “อย่าได้ลืมคู่เรียงหมอนแต่แรก”
- ย20 「醉來真個玉山頹」 → “เมาแล้วช่างเหมือนภูเขาหยกถล่มจริง ๆ” คงภาพ
- ย21/ย23 มนตร์ 「𠲛噓呵吸嘻吹呼」 → “หุยซวีเฮอซีซีชุยฮู” ถอดเสียงทีละพยางค์; 𠲛 ยังไม่พบคำอ่านที่ยืนยัน ใช้ huí ชั่วคราวตามรูปในสแกน (口+囬) ขอผู้ตรวจดู
- ย25 「潑老天殺的」 → “ไอ้เฒ่าชั่วฟ้าผ่าตาย” (คำด่าสาปแช่งไทยที่เทียบได้)
- ย25 กวีปิด 「近木叉人」 → “มาประชิดคนมู่ชา” คงถอดเสียง 木叉 ตามแถว 木叉行者 (สแกนตรงไฟล์ S068); ความหมายในกวีไม่แน่ชัด (อาจล้อ 行者 ผ่านชื่อ 木叉行者) ไม่ตีความเพิ่ม ขอผู้ตรวจดู
