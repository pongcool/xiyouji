## การตัดสินระหว่างแปล
- ย2, ย20, ย25, ย27 七絕山 / 稀柿衕 / 稀屎衕 → “เขาเจ็ดเลิศ / ตรอกพลับเละ / ตรอกขี้เละ” แปลความหมายแทนถอดเสียง เพราะ 三藏 ถาม 何為七絕 แล้วตัวบทอธิบายชื่อ และ 柿/屎 เป็นการเล่นเสียง (เชิงอรรถ 067-1); 駝羅莊 ถอดเสียง “หมู่บ้านถัวหลัว”
- ย9 原來晒乾疤 → “ที่แท้กลายเป็นสะเก็ดแผลตากแห้ง” วรรคนี้ไม่มีประธานและไม่สัมผัสคู่กับวรรคข้างเคียง แต่สามแหล่งตรงกัน แปลตามตัวอักษร ขอผู้ตรวจดู; 相應沒頭髮 → “รับมือได้แต่ไม่มีผม” คงการซ้ำคำ 相應
- ย9 法官 → “หมอพิธี” (ผู้ประกอบพิธีปราบผี ไม่ใช่ตุลาการ)
- ย12 使勾悶數錢糧 → “ต้องจ่ายเงินและเสบียงไปอีกโขเปล่า ๆ” อ่าน 勾悶數 เป็นจำนวนมากพอ/เสียเปล่า ความเป็นสำนวนไม่ยืนยัน
- ย14 吃了磨刀水的秀氣在內 → ‘กินน้ำลับมีดเข้าไป ความสง่าจึงอยู่ข้างใน’ พร้อมเชิงอรรถ 067-2 ว่า 秀氣 พ้องเสียง 銹氣 (สนิม) ตามรูปคำพูดตัดท้าย
- ย14 表弟、姨兄 → “ลูกพี่ลูกน้องผู้น้อง พี่ลูกป้าน้า” ไม่ระบุฝ่ายพ่อ/แม่ของ 表 เพราะต้นฉบับไม่ชัด
- ย21 沒蛇弄 → “ไม่มีงูให้เล่น” และ ย23 好打死蛇 → “ชอบตีงูตาย” แปลตรงตัว ไม่ใส่เชิงอรรถอธิบายสำนวน เพราะยังไม่ได้ตรวจแหล่งนิยาม
- ย23 贛保船 → “เรือกั้นเป่า” ถอดเสียงชนิดเรือ ไม่ทราบความหมายแน่ (贛 อาจหมายถึงถิ่นเจียงซี) ขอผู้ตรวจดู
- ย4 醋燒葵湯 → “แกงผักมาลวาต้มน้ำส้ม” (葵 = 冬葵 ผักมาลวา); ย26 科豬 → “หมูตอน” ตามบริบท ความหมาย 科 ไม่ยืนยัน
- ย18 好是耳聾口啞 → “ดีละ ทั้งหูหนวกทั้งปากใบ้” อ่าน 好是 เป็นคำประชด
