## การตัดสินระหว่างแปล
- ชื่อบท 求方 → “แสวงหาตำรับยา”; 甘泉活樹 → “ใช้น้ำพุหวานชุบต้นไม้คืนชีพ”; 方/無方 ในเนื้อเรื่องใช้ “ตำรับ/ไม่มีตำรับ”
- ย1 心上刃 / 寸邊而 / 刃字 → คงภาพรูปอักษร (คมมีดบนใจ = 忍; 寸 ข้าง 而 = 耐) พร้อมเชิงอรรถ 026-1 แทนการแปลเป็น “อดกลั้น/อดทน” ตรง ๆ
- ย2 好小家子樣 → “ใจแคบอย่างคนบ้านเล็กบ้านน้อย”; 不爭競，我肯善自饒你 → “ไม่รบรากัน ข้าจะยอมปล่อยเจ้าดี ๆ หรือ” (คำถามย้อน)
- ย3 當面人情鬼 → “ผีน้ำใจต่อหน้า”; 光皮散兒 → “ท่าเกลี้ยงเกลา”; 那話兒經 → “คัมภีร์ไอ้นั่น” ตาม 那話兒 และ 緊箍經
- ย4 衣服禳了 → “เสื้อผ้าเปื้อน” (อ่าน 禳 ตามบริบทซักลงแป้ง); 若瘦了些兒，不出門 → “ข้าไม่ยอมออกจากประตูนี้ไปแน่” แปลตามตัว ขอผู้ตรวจดู
- ย6 萬壽草還丹 → “โอสถคืนธาตุแห่งพืชหมื่นอายุ” อ่าน 萬壽 เป็นความหมาย (อาจพ้องชื่อเขาว่านโซ่ว) ขอผู้ตรวจดู; 脫性命 → “เอาชีวิตเข้าแลก”
- ย7 儘有幾分醋我 → “ชักจะเกรงข้าอยู่หลายส่วน” อ่าน 醋 = 怵 กลัว ขอผู้ตรวจดู
- ย8 太乙散數 → “ยังอยู่ในจำนวนเซียนอิสระไท่อี่”; 蜾蟲鱗長 → “สัตว์ไร้ขน หรือสัตว์มีเกล็ด” (蜾 = 倮)
- ย9 執星籌，添海屋 → เชิงอรรถ 026-2 เรื่องเรือนกลางทะเล
- ย10, ย12 มุกของ C036 (加冠進祿, 添壽/添福/添祿, 番番是福, 回頭望福, 四時吉慶) แปลตรงพร้อมเชิงอรรถ 026-3 ถึง 026-6 เว้น 回頭望福 ที่ไทยรับมุกได้เพราะ 福星 = “ดาววาสนา”
- ย15 靦面相迎 → “เข้าไปทักต่อหน้า” (อ่าน 靦面 = 覿面) ขอผู้ตรวจดู; 起手了 → “คารวะละ” ตาม 起手 ใน 025
- ย16 朝上進禮 → “คารวะไปทางเบื้องบน” (ต่อ C111)
- ย17 閣氣 → “คับแค้นใจ”
- ย18 玉液錕鋘鐵石堅 → “น้ำหยกกับเหล็กคุนอู๋ แกร่งดั่งเหล็กดั่งศิลา”; 億萬年 → “นับหมื่นนับแสนปี” (คำขยายเกินจริงในกวี)
- ย22 四聖/六凡 → “สี่อริยะ/หกปุถุชน”; 少林 → ถอดเสียง “เส้าหลิน” ไม่ถอดรหัสอุปมา
