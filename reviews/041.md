## การตัดสินระหว่างแปล
- ย1 กวีเปิดบทไม่มีคำเกริ่น แปลเป็นกวีหกวรรคตามเครื่องหมายวรรคตอน (ไฟล์เขียนติดเป็นร้อยแก้ว wikisource แยกเป็นสองบาท)
- ย6, ย20 紅孩 (ไม่มี 兒) → “หงไห” คงรูปย่อตามตัว ไม่เติมเป็นหงไหเอ๋อร์
- ย7 C001 เรียก C129 「哥哥」 → “พ่อหนุ่ม” ไม่แปล “พี่” เพราะผู้พูดเพิ่งอ้างตนเป็นอาและเรียกหลาน; ใช้เป็นคำเรียกเด็กแบบเอ็นดูแกมเยาะ ขอผู้ตรวจดู
- ย7 「綽甚聲經兒」 → “พล่ามสวดอะไรของเจ้า” อ่าน 聲經 เป็นการสวดท่อง (คำด่าว่าพูดซ้ำซาก)
- ย8 「正果善財郎」 → “หนุ่มซ่านไฉแห่งผลแท้” ถอดเสียงชื่อ เชิงอรรถ 041-1 บอกความหมายตามตัวและที่มาในคัมภีร์พุทธ ไม่บอกเหตุการณ์ล่วงหน้า
- ย13 「早是我有些南北哩」 → “ดีที่ข้ายังพอมีไหวพริบอยู่บ้าง” (南北 = รู้ทิศทาง/รู้ทางหนีทีไล่)
- ย13 「沒天理」 → “ไม่มีหลักฟ้าเลย”
- ย14 「眾毛攢毬」 → “ขนหลายเส้นรวมเป็นลูกขนได้” คงภาพสุภาษิต
- ย16 ทัพสัตว์น้ำ: ชื่อปลาที่ไม่ยืนยันชนิดไทยถอดเสียง (鱯 ปลาหู้, 鯖 ปลาชิง, 鯕 ปลาฉี); 紅眼馬郎 → “หนุ่มม้าตาแดง” แปลตามตัวเพราะไม่ยืนยันว่าเป็นชื่อปลา
- ย25 「你才子發昏的」 → “ท่านเพิ่งจะเป็นลมไปเมื่อกี้” อ่าน 才子 = 才自/剛才
- ย38 興烘掀 / 掀烘興 → “ปลุกโหมพลิก / พลิกโหมปลุก” แปลความหมายและคงการกลับลำดับ; 壽延千紀 → “อายุจะยืนยาวพันรอบนักษัตร” (紀 = รอบสิบสองปี)
