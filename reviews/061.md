## การตัดสินระหว่างแปล
- ชื่อบท 「助力敗魔王」 → “ช่วยแรงตีราชามารแตกพ่าย”; 「三調芭蕉扇」 → “เล่นเล่ห์ชิงพัดใบกล้วยครั้งที่สาม” ตาม 059/060 (wikisource ใช้ 破 หมายเหตุรูปอื่น 敗; ไฟล์ใช้ 敗 ไม่ได้เปิดสแกนหัวบทเพราะความเท่ากัน)
- ย2 「綽著經兒」 → “พูดตามน้ำ”; 「結了一場乾夫妻」 → “เป็นผัวเมียลม ๆ แล้ง ๆ อยู่ยกหนึ่ง” (乾 = ในนามไม่จริง)
- ย3 กวี 「粗心大聖將人騙」 → “ต้าเซิ่งใจหยาบหลอกคน” (將人騙 อ่านว่าต้าเซิ่งเป็นผู้หลอก C130 คู่กับ 把扇誆); 「伶俐的齊天聖」 ไม่มี 大聖 จึงแปลความหมาย “ปราชญ์เสมอฟ้า” ตาม X030; 「齊天孫大聖」 → “ฉีเทียนซุนต้าเซิ่ง”
- ย5 「血皮脹的遭瘟」 → “ไอ้หนังพองเลือดตัวซวยเจอห่า”; ย7 「結心癀」 → “ไอ้ตัวนิ่วอุดใจ” (癀 โรคนิ่ว/ดีวัว ใช้ด่าวัว)
- ย10 「轉路走他娘罷」 → “อ้อมทางไปแม่มันเสียเลย” คงคำหยาบ
- ย10 กลอน 「牛王本是心猿變」 → “ราชาวัวแต่เดิมคือวานรใจแปรไป” แปลตามตัว ไม่ถอดรหัส
- ย11 「木生在亥配為豬」「申下生金本是猴」 แปลตามตัว เชิงอรรถเฉพาะการคู่นักษัตร ไม่อธิบายห้าธาตุเกิน
- ย12 「䬲草」 → “ไอ้กินหญ้า” ความหมาย 䬲 ไม่ยืนยัน (สแกนตรงไฟล์) แปลตามบริบทคำด่าวัว ขอผู้ตรวจดู; 「老犧」「犧牲」 → “วัวเครื่องเซ่น”
- ย13, ย14 「天鵝」 → “ห่านฟ้า” แยกจาก 鳳 “หงส์” ใน ย15
- ย15 「乜乜些些」 → “ทำท่าซื่อบื้อ”; 「賴象」 → “ช้างใหญ่” (賴 ความไม่แน่ชัด)
- ย17 「概眾…圍得水泄不通」 → “ทุกฝ่าย…ล้อมไว้แน่นจนน้ำไม่รั่วไหล”
- ย20 ชื่อเทพวัชระ: ถอดเสียงส่วนชื่อ (潑法, 勝至, 永住) แปลส่วนคุณนาม (神通廣大, 法力無量, 不壞尊王); 「毘盧沙門大力金剛」 → “เทพวัชระพลังมหาศาลไวโรจนสมณะ” ประกอบจาก 毘盧 ไวโรจนะ + 沙門 สมณะ ขอผู้ตรวจดูว่าควรอ่านเป็น 毘沙門 (เวสสุวรรณ) ที่มี 盧 แทรกหรือไม่ (ไม่ได้เปิดสแกนจุดนี้)
- ย21 「父王」 คำ C016 → “เสด็จพ่อ” ตามคำเรียกของ C016 เองใน 004/006 ไม่ใช้ “ท่านพ่อ” ของแถว 父王 บท 042 (ผู้เรียกต่างคน)
- ย23 「穿縞素似比丘」 → “สวมขาวล้วนดั่งภิกษุ” คงคำ 比丘 ตามตัว
- ย24 「叩齒叩頭，受身受命」 → “ขบฟันโขกศีรษะ น้อมรับคำด้วยกายและชีวิต”
- ย27 「我等也修成人道」 → “พวกข้าก็บำเพ็ญจนได้มรรคแห่งมนุษย์”; 「見今真身現象歸西」 → “บัดนี้ร่างแท้ปรากฏรูปเดิมไปสู่ตะวันตกแล้ว” (หมายถึง C014 ตามบริบท ไม่เติมชื่อ)
