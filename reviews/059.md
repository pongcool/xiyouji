## การตัดสินระหว่างแปล
- ชื่อบท 「一調芭蕉扇」 → “เล่นเล่ห์ชิงพัดใบกล้วยครั้งที่หนึ่ง” (調 อ่าน diào = หลอก/สับเปลี่ยน ทั้งสามบทเป็นการใช้เล่ห์เอาพัด) ขอผู้ตรวจดู
- ย1 「緊鎖牢䪊」 → “ล่ามบังเหียนไว้ให้แน่นหนา”; ย2 「鎖䪊猿馬」 → “ล่ามบังเหียนวานรกับม้า” คงภาพ 心猿意馬 ไม่ถอดรหัส (S067)
- ย3 「斯哈哩國」 → “แคว้นซือฮาลี” (哩 อ่าน lī เป็นเสียงถอดชื่อต่างแดน); 「乃日落之處」 → “ที่ตะวันตกดิน”; 「朝三暮二」 → “เช้าสามเย็นสอง” คงสำนวน (ความลังเลกลับกลอก)
- ย4 「𢯌靸䩺鞋」 อักษรหายาก แปลตามความว่า “รองเท้าแตะ” (靸 รองเท้าไม่มีส้น) ไม่เปิดสแกนเพราะไม่กระทบความ
- ย8 「隔年焦」 → “กลุ้มใจล่วงหน้าข้ามปี”
- ย11 「不尚五六里」 อ่าน 尚 = 上 → “ไม่เกินห้าหกลี้” (wikisource ตรงไฟล์)
- ย11 「莫認往時之溲話」 → “อย่าไปรับเรื่องเก่าค้างคืนเหล่านั้น” (溲 = บูดค้าง)
- ย13 「毛兒女」/「毛女」 → “เด็กหญิงขนดก” แปลตามตัว (อาจหมายถึงสาวน้อยธรรมดาตามภาษาพูด หรือ 毛女 ผู้บำเพ็ญจนขนขึ้นตามตำนานเต๋า ข้อความถัดไป 「一身藍縷無妝飾，滿面精神有道心」 เข้ากับอย่างหลัง) ขอผู้ตรวจดู
- ย14 「兇比月婆容貌」 → “ดุร้ายเทียบโฉมหน้ายายพระจันทร์” แปลตามตัว ไม่พบหลักฐานว่าเป็น 月孛 จึงไม่ตีความ
- ย15/ย21/ย22 叔叔/老叔/孫叔叔 → “ท่านอา/ท่านอาซุน”: C001 อ้างเป็นน้องร่วมสาบานของสามี C130 คำ 叔叔 ที่ภรรยาใช้เรียกน้องสามีเป็นคำเรียกตามมุมลูก ไทยใช้ “อา” ได้ตรงกันและคงน้ำเสียงข่มขู่/ยอมแพ้; ต่างจาก 伯伯 “พี่สามี” (แถว 414) เพราะที่นี่ C001 จงใจใช้ฐานะผู้ใหญ่ของเด็ก ขอผู้ตรวจดู
- ย15 「不生不滅，不垢不淨」 ตามรูปหฤทัยสูตรในบท 019 “ไม่เกิดไม่ดับ ไม่แปดเปื้อนไม่บริสุทธิ์”
- ย16 「讓娥流」 → “ยอมให้สตรี”; 「一搧揮動鬼神愁」 → “พัดทีเดียวโบกไหวจนผีและเทพหวาดหวั่น”
- ย19 「太陰之精葉」 → “ใบไม้อันเป็นแก่นแท้แห่งไท่อิน” (คู่กับ 太陽真火 “ไฟแท้แห่งไท่หยาง” ย3)
- ย21 「坐碗兒」 → “ชามแกง…สักชาม” ไม่ได้รักษาเล่นคำ 坐 (กระทืบลง) เพราะไม่มีคำไทยตรง; 「點心」 รักษาเล่นคำด้วยเชิงอรรถ 059-3
- ย24/ย25 「兩股毫毛」 → “ขนที่ต้นขาทั้งสองข้าง” (股 = ต้นขา) อีกทางอ่านได้ว่า “ขนสองกำ” ขอผู้ตรวจดู
- ย26 「雕嘴魚腮鬼」 → “ผีปากเหยี่ยวแก้มปลา”; 「黃糧米飯」 → “ข้าวฟ่างเหลือง”
