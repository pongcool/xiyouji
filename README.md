# ซีโหยวจี้ — โครงการแปลไทย

แปล 西遊記 (Xīyóujì) จากต้นฉบับรายบท `chapters/001.md`–`100.md` ที่แบ่งจากไฟล์ผู้ใช้ เป็นไทยครบเรื่อง ไม่ย่อหรือเรียบเรียงใหม่ ใช้ชื่อเรื่อง “ซีโหยวจี้” และชื่อคนจีนกลาง เช่น ซุนอู้คง จูปาเจี้ย ตาม X006 ไฟล์รวมเดิมถูกลบตามคำสั่งผู้ใช้แล้ว ความหมายยึดสแกน 世德堂 1592 เป็นหลักในจุดที่เปิดเทียบ ไฟล์รายบทเป็นไฟล์ทำงานและฐานป้ายหน่วยเทียบ (X024, X025)

## เริ่มงาน
ขั้นงาน ไฟล์ที่ต้องอ่าน และการส่งต่อดู [AGENTS.md](AGENTS.md) หลักภาษาดู [TRANSLATION_GUIDE.md](TRANSLATION_GUIDE.md) สถานะรายบทดู [PROGRESS.md](PROGRESS.md)

สแกน 世德堂 PDF (1.64 GB) ไม่อยู่ใน Git หลัง clone ให้รัน `python -X utf8 tools/fetch_sources.py` เพื่อดาวน์โหลดจาก GitHub Release `sources-scan-1592` มาไว้ใน `sources/` และตรวจ SHA-256 ตรวจไฟล์ที่มีอยู่แล้วด้วย `--check`

## ต้นฉบับและหน่วยเทียบ
ไฟล์ต้นทางระบุ Project Gutenberg eBook 23962, Title: 西遊記, Author: Cheng'en Wu, Release date: December 22, 2007 ข้อมูลนี้อ้างจาก metadata ภายในไฟล์ ไม่ได้ตรวจเทียบฉบับพิมพ์หรือเว็บทั้งเรื่อง

แยกแล้ว 100 บทใน `chapters/001.md`–`100.md` เก็บเนื้อเรื่องและการตัดบรรทัดเดิม ใช้กลุ่มบรรทัดคั่นด้วยบรรทัดว่างเป็นหน่วยเทียบ ไม่ถือทุกบรรทัดพับคำเป็นย่อหน้า ดูข้อจำกัดและหัวบท 047 ใน [SOURCE_ISSUES.md](docs/SOURCE_ISSUES.md) ตรวจ hash หัวบท และจำนวนหน่วยกับ manifest (สร้างใหม่ 2026-11-05 จาก chapters/ เพราะไฟล์เดิมไม่เคย commit; X013) ด้วย `python -X utf8 tools/prepare_xiyouji.py --check` และ [manifest](docs/SOURCE_MANIFEST.json)

## โครงสร้าง
- `chapters/` — ต้นฉบับรายบท; ห้ามแก้เงียบ ๆ
- `sources/` — ฉบับสแกน 世德堂 (1592) เป็น PDF ซึ่งเป็นหลักของความหมายตาม X024 และข้อความ 維基文庫 รายบทเป็นแหล่งช่วยอ่าน; chapters/ ยังเป็นไฟล์ทำงานและฐานป้ายหน่วยเทียบ; วิธีใช้ดู AGENTS.md
- `translations/th/` — คำแปลจริงเท่านั้น
- `reviews/` — ตรวจตนเอง ตรวจอิสระ ผลตอบข้อพบ และตรวจข้ามบท
- `docs/` — กติกาชื่อ ภาษา ปัญหาต้นฉบับ และแผนที่ไฟล์
- `tools/` — เครื่องมือตรวจรูปแบบ ศัพท์ รูปแปร จำนวนคำ และดึงแถวเอกสารกลางรายบท (`chapter_lookup.py`) และสร้างฉบับรวมเล่ม HTML/EPUB ลง build/ (`build_book.py`)
- `book/` — ส่วนหน้า ส่วนท้าย และ metadata ของฉบับรวมเล่ม
