# ตารางถอดเสียงจีนกลางเป็นไทย

ใช้กับชื่อเฉพาะทุกชื่อตามข้อยุติ X002 เพื่อให้พยางค์เดียวกันสะกดเหมือนกันทุกบท
ตารางนี้เป็นกติกาของโครงการเพื่อสะกดเสียงเดียวกันอย่างสม่ำเสมอ ไม่ได้อ้างว่าตรงกับเกณฑ์ของหน่วยงานใดทุกข้อ

## ขั้นตอน
1. หาคำอ่านพินอินพร้อมวรรณยุกต์ของแต่ละตัวจากบริบทและแหล่งที่ตรวจสอบได้ ระวังอักษรหลายเสียง ไม่ถือว่าตารางนี้ยืนยันคำอ่านชื่อทุกชื่อ
2. แปลงพยัญชนะต้นและสระตามตารางด้านล่าง
3. ใส่วรรณยุกต์ตามกลุ่มอักษร
4. เขียนชื่อติดกันไม่เว้นวรรค รวมถึงยศหรือคำนำหน้าที่ติดชื่อ ตามรูปที่ลงทะเบียนไว้
5. ค้นใน GLOSSARY.md ก่อนเสมอ ถ้ามีรูปอยู่แล้วให้ใช้รูปนั้น ถ้าเป็นชื่อใหม่ให้ลงทะเบียนพร้อมพินอินในช่องหมายเหตุ

## ตำแหน่งวรรณยุกต์
- วางรูปวรรณยุกต์บนพยัญชนะต้นตามอักขรวิธีไทย เมื่อมี ห นำ ให้วางบนตัวที่สอง เช่น หนี่ว์, เหล่า
- พยางค์ อวี วางรูปบน ว เช่น อวี้, อวี่
- ไม่ใส่วรรณยุกต์เพิ่มเพื่อให้ออกเสียงตามหูไทย ใช้ตามตารางเท่านั้น

## ส่วนชื่อและส่วนแปลความหมาย
- ชื่อบุคคลถอดเสียงจีนกลาง ฉายาและตำแหน่งพิจารณาหน้าที่แล้วลงทะเบียนแยก ไม่ยกกติกาชื่อเทพจากโครงการเดิมมาใช้ทั้งหมด
- ส่วนบอกประเภทสถานที่แปล เช่น 山 เขา, 洞 ถ้ำ, 河 แม่น้ำ, 寺 วัด, 宮 วัง/วิหาร ตามหน้าที่ในฉาก
- ของวิเศษ วิชา และคำศาสนาให้แปลความหมายเมื่อยืนยันได้ ไม่ถือทุกคำว่าเป็นชื่อเฉพาะ
- ชื่อเรื่องใช้ “ซีโหยวจี้” (西遊記, Xīyóujì) ตาม X006 ชื่อเรื่องและชื่อคนใช้จีนกลาง ไม่ยกเว้นเป็นชื่อจีนถิ่น
