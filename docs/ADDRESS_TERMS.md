# สรรพนามและคำเรียก — ซีโหยวจี้

ค่าเริ่มต้นตาม X005 เป็นกติกาภาษา ไม่ใช่ข้อมูลว่าตัวละครใดพูดคำเหล่านี้แล้ว ไม่มีการยกสถิติหรือคู่สนทนาจากเรื่องเดิมมาใช้

## หลักตัดสิน
ดูผู้พูด ผู้ฟัง ฐานะ และน้ำเสียงก่อนเทียบคำจีน ไม่ใช้ราชาศัพท์เพียงเพราะคำเรียกมี 王 ตัวละครเรียกตัวเองด้วยชื่อให้คงชื่อ ไม่เปลี่ยนเป็น “ข้าพเจ้า” คำอวดตนและด่าทอให้รักษาระดับที่ต้นฉบับมี ไม่บังคับทุกคนเป็นข้า/ท่านจนเสียงเหมือนกัน

## ค่าเริ่มต้น
| จีน/บริบท | ไทยที่ใช้ | เงื่อนไข |
|---|---|---|
| 我 / 吾 / 俺 ทั่วไป | ข้า | ปรับพหูพจน์และน้ำเสียงตามฉาก |
| 我等 / 吾等 | พวกเรา | ไม่สลับกับเอกพจน์ |
| 弟子 แทนตัวต่ออาจารย์ | ศิษย์ | ถ้าเป็นคำนามให้แปลตามประโยค |
| 師父 / 師傅 | ท่านอาจารย์ | ตรวจว่าเป็นผู้สอนจริงหรือคำยกย่อง |
| 師兄 / 師弟 | ศิษย์พี่ / ศิษย์น้อง | บันทึกคู่สนทนาจริง ไม่สรุปว่าเป็นญาติ |
| 貧僧 / 老衲 | อาตมา | พระพูดกับฆราวาส; ต่ออาจารย์/กษัตริย์ดูฐานะในฉาก |
| 貧道 | อาตมา | นักพรตถ่อมตน; คำบรรยายต้องทำฐานะนักพรตชัด |
| 朕 / 寡人 | เรา | ผู้ครองราชย์แทนตัว |
| 臣 / 微臣 ต่อกษัตริย์ | ข้าพระองค์ | ผู้ฟัง ฝ่าบาท; ใช้ราชาศัพท์เท่าที่จำเป็น |
| 妾 / 妾身 | ข้า / หม่อมฉัน | หม่อมฉันเมื่อทูลกษัตริย์; ไม่เดาฐานะชายาหากไม่มีหลักฐาน |
| 小人 / 小的 / 在下 | ข้าน้อย | ตรวจว่าถ่อมตน ไม่ใช่คำนาม “คนเลว” |
| 孩兒 | ลูก | เมื่อพูดกับบิดามารดาจริง |
| 大王 | ท่านราชา / ท่านเจ้าผู้ครอง | รูปชั่วคราว ต้องเลือกและลงทะเบียนตามผู้ฟัง; ไม่เท่ากษัตริย์มนุษย์ทุกฉาก |
| 老孫 / 俺老孫 และคำอวดตนคล้ายกัน | คงชื่อ/แซ่และน้ำเสียงอวดตนตามฉาก | ลงทะเบียนรูปจริงเมื่อพบ ไม่แปล 老 เป็นความชราโดยอัตโนมัติ |

กรณียกเว้นตามน้ำเสียงต้องบันทึกเหตุผลใน reviews/NNN.md คำที่ยังไม่มีให้เพิ่มเมื่อพบจริง ผู้เล่าใช้ชื่อ/เขา/นางเมื่อระบุชัด ไม่ใช้ “มัน” เป็นค่าเริ่มต้นกับตัวละครที่มีสติปัญญา ไม่เดาเพศจากคำเรียก

## คู่สนทนาเฉพาะ
